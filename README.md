# APEX Expert Drills

A 12-week, 1-hour-a-day plan for expert Oracle APEX, modern JavaScript and CSS.

- `index.html`: the whole app in one file, with a calendar of day tiles. Each day has collapsible topics containing workspace steps, runnable examples and three exercises.
- Week 1 is fully written. Weeks 2–12 list their topics; content is added week by week.
- Screenshot slots (`data-shot="…"`) get filled from a real APEX workspace.

This branch has nothing in common with `main` (the kids' Daily Drills app); it's an orphan branch on purpose.
